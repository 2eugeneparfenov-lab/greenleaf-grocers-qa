Bug Expired promo code returns HTTP 500 instead of a validation error

Severity
High
Priority
High
Evidence
evidence/api_response.json

Environment

Tool
api_probe.py (local API probe — Postman equivalent)
Method
POST
Url
http://localhost:3000/api/promo/validate
Request Body
{ "code": "EXPIRED20" }
Application
GreenLeaf Grocers (capstone_module_1)

Preconditions

GreenLeaf Grocers is running on localhost:3000 and the promo validation API is available.

Steps to reproduce

  1. Run python3 tools/api_probe.py from the lab folder.
  2. Send POST /api/promo/validate with the request body containing code EXPIRED20.
  3. Observe the returned HTTP status and response.

Expected result

The API should return a controlled 4xx response, such as HTTP 400, with a clear message that the promo code is invalid or expired.

Actual result

The API returns HTTP 500 Internal Server Error with a generic internal error response.

  "response_body": {

      "message": "Internal server error."
    }
  },

  "url": "http://localhost:3000/api/promo/validate"
